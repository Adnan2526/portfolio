# Syed Adnan S A Portfolio

A simple personal portfolio website built for showcasing skills, education, projects, and contact information.

## Files
- `index.html` — portfolio page structure
- `styles.css` — styling and responsive layout

## Preview locally
Open `index.html` in a browser, or run a small local server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Customization
Update the content in `index.html` with your own:
- name and title
- about summary
- education details
- project descriptions
- contact links

This project is ready to use as a professional portfolio for internship applications and networking opportunities.
